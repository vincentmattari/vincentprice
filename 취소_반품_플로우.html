유형별 상태값 변화

상태값 정의

A. 반품신청서견적팀 · 취소리스트

신청전→신청완료/신청불필요/재판매신청불필요
  • 취소 처리되면 기본값 신청전
  • 매입처에 반품신청서를 작성하면 신청완료. 신청완료 건만 반품배송 진행
  • 매입처 발주상태가 취소이고 미차감이면 신청불필요. 재고에서 제외하고 종료
  • 회수완료·입고 상태에서 판매되면 재판매신청불필요 추가 — 자동 선택 또는 사용자 선택. 이미 낸 신청서의 철회는 견적팀이 매입처와 직접 처리

B. 회수물류팀

회수전→회수중→회수완료/null
  • 기본값 회수전 (문서의 "미회수")
  • 공장에서 회수를 시작하면 회수중
  • 회수해서 입고되면 회수완료. 이때부터 판매 가능
  • 신청불필요 건은 공장으로 나가지 않았으므로 null

C. 반품배송물류팀

입고→출고준비→배송중→배송완료/null
  • 기본값 입고. 다음날 반품하지 않는 부품은 입고 유지
  • 신청완료 부품 중 다음날 반품할 부품은 출고준비. 이때부터 판매 불가
  • 반품배송이 출발하면 배송중, 도착하면 배송완료
  • 재판매·신청불필요 건은 null

D. 계산서 취소회계팀

취소전→취소요청중→취소완료/null
  • 기본값 취소전
  • 반품배송완료 이후 취소요청중
  • 매입처의 계산서 취소를 확인하면 취소완료. 재고에서 반품완료로 출고
  • 재판매·신청불필요 건은 null이며 회계팀 목록에서 제외

판매·재고 규칙

구간판매재고
취소 처리 ~ 회수완료 전불가포함
신청불필요 선택불가제외
회수완료 + 입고 (출고준비 전, 신청서 상태 무관)가능포함
판매됨 → 재판매신청불필요—판매 출고
출고준비 ~ 계산서 취소완료 전불가포함
계산서 취소완료—반품완료 출고

개발 반영 사항

  • 주문상세 · 취소발송 전 취소는 주문에서 부품 삭제 후 종료
  • 주문상세 · 취소발송 후 취소는 미입고분을 입고 처리한 뒤 취소, 취소와 동시에 재고 전환
  • 취소리스트반품신청서 상태 4종: 신청전 / 신청완료 / 신청불필요 / 재판매신청불필요
  • 취소리스트신청불필요 선택 시 재고에서 제외, 회수·반품배송·계산서 취소 null, 각 팀 목록에서 제외
  • 재고 · 판매판매 가능 조건은 회수완료 + 입고 (출고준비 전)
  • 재고 · 판매판매 시 재판매신청불필요 자동 선택 또는 사용자 선택, 반품배송·계산서 취소 null
  • 물류출고준비 전환은 신청완료 건만 가능, 출고준비부터 판매 불가
  • 회계 · 재고계산서 취소완료 시 재고에서 반품완료로 출고
